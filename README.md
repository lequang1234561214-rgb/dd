# Video Focus — Gói tải Windows 10/11 x64

Nhánh này chỉ chứa gói ZIP được chia phần và tệp tự ghép/giải nén.

## Tải và mở

1. Tải ZIP của toàn bộ nhánh từ GitHub (Code → Download ZIP).
2. Giải nén **toàn bộ** tệp tải xuống vào một thư mục.
3. Nhấp đúp **Giai-nen-va-chay.cmd**. Chờ ghép, kiểm tra checksum và giải nén xong; ứng dụng sẽ mở.
4. Chọn nhiều video, thư mục xuất rồi bấm **Xử lý tất cả**.

Cần khoảng 2 GB trống cho khâu chuẩn bị và thêm dung lượng cho video đầu ra. Đã kèm Python và FFmpeg; không cần cài thư viện hoặc API key. Lần sau mở cùng tệp CMD để chạy lại. Có thể chạy Kiem-tra.cmd trong app/VideoFocus-Windows-x64 để tự kiểm tra.

Bộ xử lý Windows đã được kiểm tra qua Wine; giao diện chưa kiểm chứng trên Windows thật. Nhận diện người nói/cao trào dùng ước lượng khuôn mặt, chuyển động miệng, âm lượng và chuyển động hình ảnh, có thể nhầm. Xem HUONG-DAN.txt và VALIDATION.txt trong ứng dụng.
